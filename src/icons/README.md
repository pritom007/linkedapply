# Icons

Place your extension icons here:
- `icon16.png` (16x16 pixels)
- `icon48.png` (48x48 pixels)
- `icon128.png` (128x128 pixels)

You can create simple placeholder icons using any image editor, or use online tools like:
- https://www.favicon-generator.org/
- https://favicon.io/

For now, you can use any PNG files with these names as placeholders. The extension will work without icons, but Chrome will show a default icon.
